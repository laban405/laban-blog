X / Twitter · Thread
Day 5 — M-Pesa Daraja production tips (technical authority)
🧵 5 things nobody tells you about M-Pesa Daraja in production: 1/ The STK Push callback is unreliable. Always poll the transaction status endpoint as a fallback. Don't trust the callback alone — it drops silently. 2/ Sandbox and production have very different response times. Test your UX loading states at 8–12 second delays, not 2 seconds. Users will see the difference. 3/ The OAuth token expires in 1 hour. Cache it server-side with a 55-minute TTL. Fetching a new token per request kills performance and can get you rate-limited. 4/ The ResultCode field is a string in some endpoints, an integer in others. Type your DTOs carefully or you'll have silent failures in production that only appear under specific conditions. 5/ Always verify the amount server-side. The client can pass any amount in the STK request. Validate it against your order record before confirming payment. I've built Daraja into 4+ production systems. Happy to review your integration — DM me.
