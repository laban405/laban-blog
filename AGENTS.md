# AGENTS.md

## Project
High-end personal portfolio website built with Next.js App Router, TypeScript, and Tailwind.

## Design Principles
- Minimal but premium
- Fast loading
- Smooth micro-interactions
- Strong typography
- Avoid visual clutter
- Accessibility matters

## Tech Stack
- Next.js App Router
- TailwindCSS
- Framer Motion
- shadcn/ui

## Rules
- Prefer server components by default
- Use client components only when needed
- Keep components reusable
- Avoid large files
- Use semantic HTML
- Mobile-first responsive design
- Prioritize animation smoothness and perceived performance
- Use feature based folder structure

## Commands
- pnpm dev
- pnpm lint
- pnpm build

## Done When
- Types pass
- Lint passes
- No hydration issues
- Mobile responsive
- Animations smooth at 60fps
